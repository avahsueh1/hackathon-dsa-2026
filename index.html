    Block by block

    ~ means the number is an estimate. A plain number was counted in person.

    Block-level estimates distribute each area's published monthly total across its blocks using spatial patterns from 12 physical counts (2018–2025). Blocks are indicative of where need concentrates, not exact per-block headcounts. Hatched blocks are estimated; solid blocks were physically counted that month. The street grid and labels are drawn from the block geometry itself — the page makes no external requests and renders with no network.

    Where the next shelters should go

    Is the model actually worth running?

    The obvious strategy is to build where the crowd is. That is the benchmark this has to beat, otherwise the maths is decoration. Both strategies get the same number of sites and the same bed cap.

    This model — put beds where people have no bed nearby
    Build where the crowd is

    How far people will walk changes the answer

    Downtown is only about 3.5 km across. Assume people will walk 10 minutes and every candidate site looks the same, so the model stops being useful. The 5-minute assumption is both realistic and the one that tells sites apart.

    How much of the gap each site closes

    Sites are ordered by how many people they reach. The curve bends, which is the useful part: the first few shelters do most of the work, and each one after that reaches fewer people than the last.
